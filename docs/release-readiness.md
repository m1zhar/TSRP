# TSRP release readiness

## Current candidate status (2026-10-24)

The current local candidate is intentionally **public and account-free**. `/` is available anonymously; the former `/signin` URL returns visitors to research, `/api/auth/*` returns 404, and `/api/backend-token` issues only a short-lived same-origin request token. That token is not an access-control mechanism. Do not configure an identity provider or describe account sign-in as a release requirement. The privacy page states that anyone with the URL can use TSRP and that personal/confidential information must not be entered.

Current local evidence: warnings-as-errors Python suite **479/479**, frontend utility suite **177/177** (latest on Node **24.19.0**, while the project targets Node **22.x**), focused Vercel configuration suite **9/9**, ESLint, and a fresh production build/TypeScript plus anonymous production-mode Next.js-to-ASGI synthetic smoke passed after the account-free storage adjustment. No live Yahoo or SEC requests were made. No Vercel Preview or deployment was run; no repository commit or push was made. The 144-entry working tree was pre-existing and is preserved.
